# Issue tracker: GitHub

Issues e especificações deste repositório ficam em GitHub Issues. Use a CLI `gh`.

- Criar: `gh issue create --title "..." --body-file <arquivo>`
- Ler: `gh issue view <número> --comments`
- Listar: `gh issue list`
- Comentar: `gh issue comment <número> --body "..."`
- Labels: `gh issue edit <número> --add-label "..."`

PRs como fonte de pedidos: não.

Tickets devem registrar seus bloqueios no corpo. Quando a plataforma aceitar dependências nativas de issues, use-as também.
