# Forgotten Trail

Demo narrativa de horror western ambientada em Ash Creek. O projeto usa Unity 6.3 LTS e URP, com builds desktop para macOS e Windows.

## Abrir o projeto

Abra esta pasta no Unity Hub usando o editor `6000.3.22f1`. O primeiro perfil visual mira 1080p/60 FPS em qualidade média. O desempenho real ainda precisa ser medido com as cenas e assets do jogo.
